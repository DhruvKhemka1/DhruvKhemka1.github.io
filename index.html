Limit Order Book & Matching Engine

An exchange-style engine that fills limit and market orders by price-time priority, handling partial fills and logging every trade.

O(log n)best price
O(1)cancel
1,000randomized test runs

Price levels are dicts of deques with heaps over bid/ask prices; cancels use lazy deletion. Verified against a brute-force reference book on 1,000 randomized 200-message sequences.

P/02 GitHub ↗

Expected Linear-Time Distribution Sort

A sort that buckets values by a CDF fit to a random sample — uniform, normal or exponential via a Kolmogorov–Smirnov test, else an empirical CDF.

3.6×vs merge sort
O(n)expected
405Kreal file records

2.0–3.6× faster than merge sort on 1M generated values and up to 2.7× on real macOS file records. Heavy duplicates erase the gain; output verified against sorted().

A CLI that pulls daily prices for any ticker from Yahoo Finance, computes short- and long-window SMAs, and charts every golden and death cross.
